# Cloudflare Pages Proxy

A way to proxy Cloudflare-deployed services without using CNAMEs.

## Why?

Cloudflare's internal solutions pains me, and pointing a worker from another account to another account gives error [1014](https://developers.cloudflare.com/support/troubleshooting/http-status-codes/cloudflare-1xxx-errors/error-1014/).
